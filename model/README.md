# Operational protocol qualification

Edit.tla is a *seed* for TLC, not a complete model of protocol /1. Terminal and deliberately unresolved unknown states may stutter; deadlock checking is disabled for this seed only. Run TLC on Edit.cfg, retain state count, constant/config hashes, invariants and raw trace. No liveness claim follows. The local Python byte-vector checker does not run TLA+.

EditSafety.tla includes draft TLAPS initiation and preservation proofs for that seed. With the pinned tools, run java -cp "$TLA2TOOLS_JAR" tlc2.TLC -config Edit.cfg Edit.tla and tlapm EditSafety.tla from this directory in an isolated writable build tree. Retain all failed obligations.

Expand before SG07. Include at least two prepared IDs, two stable request keys, two clients, unrelated simultaneous file captures, same-key/different-digest conflicts, cancellation, alias epoch rotation, observed predecessor changes, claim journaling before IO, post-rename/pre-fsync power loss, historical lookup after revoke, interrupted stdio and partial multi-file results. Explore resource exhaustion, prepare eviction, competing observers and a blocked owner. A local generation by itself cannot fence an uncooperative filesystem writer. State the private, single-writer/cooperating-process and directory-handle assumptions. Procure fresh actual WSL evidence for those assumptions.

TLAPS producer: build an inductive StrengthenedInv with well-typed counters, phase/predecessor coherence, provenance of every confirmation, and unique live claims for a key. Discharge Init => Inv, Inv /\ Next => Inv', Inv => Safety, action by action for the expanded model. Prove acknowledged repeats are observational reads and revoked/stale transitions cannot issue a new effect. Reconciliation must require discriminating evidence; equal content alone in an open worktree cannot establish authorship. Define abstractions from actual adapter/ledger phases, show init and each step refine a model step or stutter, and state persistence, OS, hash and grant assumptions. Store actual theorem names, backend proofs, exclusions and release-hash bridge. No omitted proofs or unchecked OBVIOUS steps. Do not imply a Lean↔TLA equivalence theorem from separate green jobs.

Required counterexamples: remove Live at write (introduce a sticky record of authority and preimage observed at the write for this check); dispatch from unknown; release a claim during active work; report confirmed on timeout; accept another key's observation. Each mutation must build and fail the intended invariant on a retained schedule. Add a rival transition in the ABA variant, or a content-only success test is vacuous. Design liveness separately and name fairness/availability assumptions. A permanently unknown outcome is permitted when evidence is insufficient.
